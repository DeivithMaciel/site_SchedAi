# 🚀 SchedAI — AI Scheduling SaaS Landing Page

A modern SaaS landing page built to showcase an AI-powered scheduling platform.
This project was designed as part of a professional front-end portfolio, focusing on clean UI, conversion-oriented structure, and responsive design.

---

## ✨ Overview

SchedAI is a fictional SaaS product that uses artificial intelligence to automate scheduling, avoid conflicts, and optimize meeting times.

This landing page simulates a real startup product, including:

* Product presentation
* Feature highlights
* Pricing plans
* Testimonials
* Call-to-action sections

---

## 🧠 Concept

The idea behind SchedAI:

> Let AI manage your meetings automatically.

The platform helps professionals and teams:

* Save time managing schedules
* Avoid double bookings
* Optimize availability with AI
* Improve productivity
